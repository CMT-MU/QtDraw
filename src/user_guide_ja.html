ユーザーガイド#

英語版はこちらです。

QtDraw を使った MultiPie の実践的なチュートリアル（PDF）があります。

このガイドでは、QtDraw の図がどう作られているかを説明します。図の構成、データ表にある各オブジェクト、MultiPie を使った描画、Python コードからの使い方です。 メニュー、マウス、キーの操作は はじめに に、すべてのメソッドは Python のコードからの利用 にまとめてあります。

1. 全体像#

物質のファイル（.cif、.vesta、.xsf）も開けます。サイトとボンド（.xsf ならグリッドデータも）の図に変換されます。

オブジェクトの位置#

どのオブジェクトも position + cell の位置に置かれます。

  • position：単位胞の分数座標で表した点。例：[1/2,1/2,0]

  • cell：格子並進 [n1,n2,n3]。基本の単位胞なら [0,0,0]

オブジェクトの向き（ボンドやベクトルなど）は、分数座標でもデカルト座標でも与えられます。どちらにするかは cartesian 列で選びます。

範囲、繰り返し、クリップ#

  • range（lower、upper）：描く範囲。分数座標で与えます。

  • repeat：すべてのオブジェクトを、範囲内のすべての格子並進の位置にも描きます。

  • clip：範囲の外にはみ出た部分を切り取ります。

  • non-repeat（View メニュー）：繰り返して描いたオブジェクトを、基本の単位胞のオブジェクトに戻します。

たとえば、立方晶の単位胞に置いた2つのサイトを 2 × 2 × 1 の範囲に繰り返すには：

from qtdraw import QtDraw

win = QtDraw()
win.add_site(position="[0,0,0]", color="red")
win.add_site(position="[1/2,1/2,1/2]", color="blue")
win.set_range(lower="[0,0,0]", upper="[2,2,1]")
win.set_repeat(True)

2. データ表#

DataSet ウィンドウ#

e キーか DataSet ボタンで DataSet ウィンドウが開きます。オブジェクトの種類ごとに、タブに分かれた表があります。

  • name が同じオブジェクトは1つのグループになります。name のチェックボックスで、グループの表示と非表示を切り替えます。

  • セルをダブルクリックすると編集できます。読み取れない値は受け付けません。

  • 右クリックで行の挿入、コピー、削除ができます。Shift または Ctrl（macOS では Cmd）+ クリックで複数の行を選び、Delete（macOS では Backspace も）で選んだ行をまとめて削除できます。

  • 描画領域でオブジェクトを右クリックすると、その行を開く、隠す、削除することができます。

3. MultiPie を使った描画#

MultiPie は、点群と空間群（磁気群も含む）の対称操作と、対称性に適合した多極子基底（SAMB）を与えます。 これを使うと QtDraw は、対称性で等価なオブジェクトをまとめて描いたり、SAMB を描いたりできます。 QtDraw は MultiPie Ver.2（2.5 以降）と Ver.3 のどちらでも動きます。MultiPie がないときは、MultiPie ボタンがインストールを提案します。

MultiPie ダイアログ#

MultiPie ボタンでダイアログが開きます。 上部で、群の種類（PG、SG、MPG、MSG）、結晶系、群の名前を選びます。QtDraw の単位胞は、群の結晶系に合わせて変わります。 Info. のボタンで、対称操作、指標表、Wyckoff サイトとボンド、積表を表示できます。 ダイアログには3つのタブがあります。

タブ

すること

Group Info.

既約表現と調和関数の分解、調和関数、Wyckoff サイトとボンドの検索と描画、原子多極子、応答テンソル

Object Drawing

代表のサイト、ボンド、ベクトル、軌道と等価なものをまとめて描く

Basis Drawing

サイト、ボンド、ベクトル、軌道のクラスターの SAMB を一覧にし、その1つ、線形結合、または複数の単位胞にわたる変調（空間群のみ）を描く

描かれるのは普通のオブジェクトなので、ほかのオブジェクトと同じようにデータ表で編集できます。

サイト、ボンド、ベクトル、軌道の与え方#

対象

形式

例

サイト

[x,y,z]

[1/3,2/3,0]

ボンド

[x0,y0,z0];[x1,y1,z1]（始点;終点）、[X,Y,Z]@[x,y,z]（ベクトル@中心）、[x0,y0,z0]:[X,Y,Z]（始点:ベクトル）

Python から#

群はタグで指定します。例：D6h（点群）、D6h^1（空間群）、MPG:1.1.1、MSG:123.345（磁気群）。 mp_* メソッドで、ダイアログと同じことができます。

from qtdraw import QtDraw

win = QtDraw()
win.mp_set_group("D6h^1")  # graphene.
win.mp_add_site("[1/3,2/3,0]")  # equivalent sites.
win.mp_add_bond("[2/3,1/3,0];[1/3,2/3,0]")  # equivalent bonds.

lst = win.mp_site_samb_list("[1/3,2/3,0]")  # SAMBs of the site cluster.
print(lst)
win.mp_add_site_samb(lst[1])  # draw one of them.

ベクトルと軌道の SAMB は、タグ（例：Q01）、タグの線形結合（例：Q02+G01）、または変調で描きます。

lst = win.mp_vector_samb_list("[1/3,2/3,0]", "M")  # magnetic-dipole SAMBs, {type: [tags]}.
win.mp_add_vector_samb("M01")
win.mp_add_vector_samb_modulation("[[M01, 1, [1/2,0,0], cos]] : [2,2,1]")  # [[tag, coefficient, k, cos/sin]] : cells.

変調には空間群の格子並進が必要です。点群で使うと、警告を出して無視されます。 ほかの例：グラフェン、Te、すべての mp_* メソッド。

4. Python コードからの使い方#

2つの使い方#

使い方

用途

QtDraw()

QtDraw のウィンドウ。スクリプトや Jupyter ノートブックから描く

create_qtdraw_file(filename, callback)

ウィンドウを出さずに .qtdw ファイルを書く（バックグラウンドの処理）

add_* の引数はデータ表の列と同じで、文字列か数値で与えます。省いた引数（または None）には既定値が使われます。

スクリプト#

from qtdraw import QtDraw

win = QtDraw()
win.set_crystal("hexagonal")
win.set_unit_cell({"a": 2.46, "c": 6.7})
win.add_site(position="[1/3,2/3,0]", size=0.2, label="C1")
win.add_site(position="[2/3,1/3,0]", size=0.2, label="C2")
win.add_bond(position="[1/2,1/2,0]", direction="[1/3,-1/3,0]")  # C1-C2.
win.set_view([0, 0, 1])  # view along c.
win.save("graphene.qtdw")
win.save_screenshot("graphene.png")  # also .pdf, .svg, ...
win.exec()  # in a script, show the window until it is closed (not needed in Jupyter).

ウィンドウを出さずに#

from qtdraw import create_qtdraw_file


def draw(widget):
    for i in range(8):
        widget.add_site(position=f"[{i/8},0,0]", size=0.05)


create_qtdraw_file(filename="chain.qtdw", callback=draw)

図から Python コードを作る#

File > Export as Python... は、今の図を、同じ図を描く Python コードとして書き出します。たとえば、手で作った図からスクリプトを始めるときに使います。win.to_python() でコードを文字列として取り出し、win.save_python("drawing.py") でファイルに保存できます。

win.save_python("graphene.py")

で、たとえば次のようなコードが書かれます。

import sys

from qtdraw import QtDraw

win = QtDraw()
win.set_model('graphene')
win.mp_set_group('D6h^1')
win.set_crystal('hexagonal')
win.set_unit_cell({'a': 2.46, 'b': 2.46, 'c': 6.7, 'alpha': 90.0, 'beta': 90.0, 'gamma': 120.0})

# site.
win.add_site(label='C1', show_label=True, position='[1/3,2/3,0]', size=0.2)
...

  • コードは今の状態から作ります。対象は、オブジェクト、単位胞、範囲・繰り返し・クリップ、表示の設定、モデル名、MultiPie の群です。カメラ（拡大や回転）、環境設定、MultiPie ダイアログは書きません。

  • 既定値と違う値だけを書きます。MultiPie で描いたオブジェクトは、mp_set_group のあとに1つずつ書きます。

  • 繰り返しが有効なときは、基本の単位胞のオブジェクトだけを書き、set_repeat(True) で繰り返します。

  • データがファイルにない等値面は書きません（コメントで知らせます）。
